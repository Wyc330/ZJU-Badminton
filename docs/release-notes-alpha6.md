**0.9.0alpha6 — 极限提速（学习坐标 + 快速命中，不限手段）**

目标是「放号瞬间 1 秒内完成选格」，这一版把**所有遍历节点树的开销**从热路径上拿掉了。

### 怎么快起来的
| 手段 | 省下的时间 |
|---|---|
| **学习式坐标缓存**：第一次跑到「同意勾选 / 我要预约 / 同伴勾选 / 同伴码输入框 / 确定 / 提交订单 / 日期箭头 / 刷新」时记住坐标，之后直接按坐标点，不再遍历节点树 | 每次 50~150ms |
| **快速文本命中**：用系统 `findAccessibilityNodeInfosByText` 判断页面切换，替代遍历全树 | 每次 40~120ms |
| **免回调点击**：`dispatchGesture` 不等回调直接发 | 每次 40~80ms |
| **填码走焦点输入框**：点坐标后用 `findFocus(FOCUS_INPUT)` 直接写文本 | ~80ms |
| 节奏再收紧：点击后 110ms / 跳页 250ms / 轮询 80ms | 累计 ~0.5s |

学习是自动的：第一次跑（或界面改版后点「清除点击缓存」）会重新学习一遍，
之后每次抢场地都走坐标快路径；某一步没点中会自动回退正常定位并重新学习。

### 放号后时间线（估算）
- 刷新 → 选中格子：**≈0.5~0.8s**（其中截图取色 ~0.3s 是系统限制的物理下限）
- 选格 → 提交订单：~1.5~2.5s（H5 页面跳转 + 同伴码弹窗，属目标 App 侧耗时）
